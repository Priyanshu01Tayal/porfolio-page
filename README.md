# 3D Personal Portfolio

A premium, modern 3D portfolio website built with React, Vite, Tailwind CSS, Three.js, React Three Fiber, and Framer Motion.

## Features
- **3D Graphics**: Interactive Earth and Star field backgrounds.
- **Animations**: Smooth scroll, framer-motion section reveals, typing effects.
- **Glassmorphism**: Modern UI with beautiful gradients and blur effects.
- **Responsive**: Fully optimized for mobile, tablet, and desktop devices.
- **Components**: Separated UI components for easy maintainability.

## Tech Stack
- React + Vite
- Tailwind CSS
- Three.js + React Three Fiber / Drei
- Framer Motion
- GSAP
- React Router DOM
- React Tilt
- React Vertical Timeline Component
- React Type Animation

## Getting Started

1. **Install dependencies**
```bash
npm install --legacy-peer-deps
```

2. **Run the development server**
```bash
npm run dev
```

3. **Build for production**
```bash
npm run build
```

## Deployment to Vercel

1. Create an account on [Vercel](https://vercel.com).
2. Connect your GitHub repository containing this project.
3. Set the Framework Preset to `Vite`.
4. Deploy the application. Vercel will automatically build and host the site using `npm run build` and serve the `dist/` directory.
